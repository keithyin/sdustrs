# STR / homopolymer 模式的 sdust 可检测性

本文列举常见 STR（short tandem repeat）与同聚物（homopolymer）模式在 **sdust（symmetric DUST）**
下的检出情况：哪些会被标记、哪些不会，以及不会的原因。

* 版本：本仓库 `sdust 0.1.2`，默认参数 `-w 64 -t 20`（除非另行注明）。
* 实测方法：把待测重复嵌在两个各 100 bp 的随机侧翼序列之间，运行 `target/release/sdust`，
  若输出区间与重复区间有重叠即记为“检出”；表中数值要求 **3 组不同随机侧翼中至少 2 组检出**。
  短于 10 bp 的情形改用直接序列，避免侧翼随机碱基把重复“接长”。
* sdust 只输出 `name start finish`，**不输出 motif，也不输出拷贝数**；“检出”＝该区域被低复杂度掩蔽。

## 0. 速查结论

| 情况 | 能否检出 |
| --- | --- |
| 周期 1–12 的精确串联重复，长度 ≳ 5×周期（同聚物下限 7 bp） | 能 |
| 周期 ≥ 13 的精确串联重复，**无论多长**（默认 `-w 64`） | 不能（窗口装不下足够的 3-mer 对） |
| 同聚物（A/T/C/G 连续 ≥ 7 bp） | 能 |
| 拷贝数不足（如 `(CA)5` 10 bp、`(CAG)4` 12 bp、`(ACGT)5` 20 bp） | 不能 |
| 退化重复：周期 2–3 分歧率 ≳ 35%，周期 5 ≳ 30%，周期 12 ≳ 10% | 不能 |
| 被 `N` / IUPAC / `-` 等非 ACGT 字符打断的短片段 | 不能（长片段仍能） |
| 散在重复、倒位（回文）重复 | 不能（本就不是“低复杂度”） |

## 1. 判定原理：周期和长度是两个门槛

sdust 的统计量不是“是否周期”，而是**窗口内相同 3-mer 的对数**：

* 滑动窗口 `W` 个碱基 → 窗口内 `n = W - 2` 个 3-mer（默认最多 `n = 62`）。
* `r`：窗口内相同 3-mer 的对数（symmetric DUST 的核心计数）。
* 判定条件：`10 * r > T * n`，即 `r / n > T / 10`；默认 `T = 20` → `r / n > 2`。
* 只要某个 3-mer 在窗口内出现次数满足 `count * 10 > 2 * T`（默认 > 4 次），
  窗口就会从左侧被收紧到该 3-mer，因此**同聚物即使远短于 `-w` 也能达标**。

对周期为 `p` 的精确串联重复（重复单元内部 3-mer 互不相同、且在窗口内均匀分布），
窗口内每个 3-mer 约出现 `n/p` 次：

```
r ≈ p * C(n/p, 2)          r / n ≈ (n - p) / (2p)
```

代入 `r/n > T/10` 得到 `n > p * (1 + T/5)`，再用 `n = L - 2`：

```
最短可检出长度      L_min = ⌈ p * (1 + T/5) ⌉ + 2       # 默认 T=20：5p + 2
窗口下限            W_min = p * (1 + T/5) + 2           # 即 -w 至少要这么大
默认参数下最大周期  p_max = (W - 2) / (1 + T/5) ≈ 12     # W=64, T=20
```

实测验证（把 1 kb 的重复从 `-w 3` 递增扫描，记录首次出现输出的窗口）：

| 周期 p | `5p+2` | 实测首次检出的 `-w` |
| --- | --- | --- |
| 6 | 32 | 32 |
| 12 | 62 | 62 |
| 13 | 67 | 67 |
| 16 | 82 | 82 |

即：**周期 13 的重复在默认 `-w 64` 下永远不可能达标**（`n` 最多 62，`r/n` 上限 `(62-13)/26 = 1.88 < 2`），
而把 `-w` 提到 67 立刻就能检出。这解释了 §3.1 的全部现象。

## 2. 能检测出来的常见模式

| 模式 | 周期 | 最短可检出长度 | ≈ 拷贝数 | 备注 |
| --- | --- | --- | --- | --- |
| `(A)n` / `(T)n` / `(C)n` / `(G)n` | 1 | 7 bp | 7 | 同聚物，最短的一类；4 种碱基表现一致 |
| `(AG)n` | 2 | 9 bp | 4.5 | |
| `(CG)n` | 2 | 11 bp | 5.5 | GC 重复 |
| `(AC)n` | 2 | 12 bp | 6 | |
| `(AT)n` | 2 | 12 bp | 6 | |
| `(CA)n` | 2 | 12 bp | 6 | 最常见的微卫星 |
| `(CAG)n` | 3 | 15 bp | 5 | 亨廷顿/脊髓小脑共济失调类三联体 |
| `(AGG)n` | 3 | 16 bp | 5.3 | |
| `(AAT)n` | 3 | 17 bp | 5.7 | |
| `(ACGT)n` | 4 | 22 bp | 5.5 | |
| `(AAAT)n` | 4 | 22 bp | 5.5 | |
| `(AACGT)n` | 5 | 27 bp | 5.4 | |
| `(ACGTCA)n` | 6 | 32 bp | 5.3 | |
| `(ACGTTCG)n` | 7 | 34 bp | 4.9 | 单元内 7 个 3-mer 互不相同 |
| `(CTCCCGCATTTA)n` | 12 | 61 bp | 5.1 | 默认参数下可检出的最长周期 |
| `(ACGGGATGTTTAG)n` | 13 | — | — | 默认参数永远检不出（见 §3.1） |

补充：

* 最短长度附近的判定有 ±1–2 bp 抖动（相位、侧翼碱基会轻微影响），表中数值是实测中位数意义上的下限。
* 大小写等价：`acgt` 与 `ACGT` 输出完全一致。
* 反链等价：`(CA)n` 与 `(TG)n` 都是低复杂度；DUST 不需要知道链方向。
* §1 的公式假设单元内各 3-mer 出现次数均匀。若单元自身重复使用某个 3-mer，计数会更集中，
  `r` 上升，实际比表格更容易检出：`(ACGTACG)n`（`ACG` 每单元出现两次）只需 27 bp，
  `(AAAAAT)n` 只需 16 bp；表中列的是“最均匀＝最难检出”的情形，可当作保守下限。
* 相邻/复合模式只要求“任一片段达标”，达标片段会被合并成一条区间，例如 `(A)30+(CA)30`、
  `(CA)30+(AACGT)30` 都会整体被标记。

## 3. 检测不到的模式，以及原因

### 3.1 周期 > 12（默认参数下最典型的漏检）

| 模式 | 长度 | 默认 `-w 64 -t 20` | `-w 67` | `-w 128` |
| --- | --- | --- | --- | --- |
| `(ACGGGATGTTTAG)153`（p=13） | 1989 bp | **无输出** | 检出 | 检出 |
| `(GACGGCGTTGTAGT)142`（p=14） | 1988 bp | **无输出** | — | 检出 |
| `(AACCGCGATTTCTTAT)125`（p=16） | 2000 bp | **无输出** | — | 检出 |

原因：3-mer 只有 `4³ = 64` 种，窗口最多容纳 `W-2 = 62` 个 3-mer。周期 `p` 的重复在窗口内
最多产生 `r/n = (62-p)/(2p)` 的分数；`p = 13` 时上限 `1.88`，低于默认阈值 `2`，
所以**重复再长也没有用**——窗口不会变长。解决方式是把 `-w` 提到 `5p+2` 以上，
或降低 `-t`（周期 13 在 `-w 64` 下用 `-t 10` 即可检出，因为 `n > 3p` 已满足）。

> 注意：周期越大，单元内部出现重复 3-mer 的概率越高（3-mer 只有 64 种），
> 一旦内部有重复，等价周期变小，就会“意外”被检出。上表的单元都刻意选成
> 所有循环 3-mer 互不相同，代表最难检出的情形。

### 3.2 长度不足（拷贝数太少）

| 模式 | 长度 | 结果 | 原因 |
| --- | --- | --- | --- |
| `A6` | 6 bp | 未检出 | 同聚物下限 7 bp |
| `(CA)5` | 10 bp | 未检出 | 下限 12 bp |
| `(CAG)4` | 12 bp | 未检出 | 下限 15 bp |
| `(ACGT)5` | 20 bp | 未检出 | 下限 22 bp |
| `(p12)5` | 60 bp | 未检出 | 下限 61 bp |
| `(p12)6` | 72 bp | 检出 | 已过阈值 |

原因：`r` 随窗口内 3-mer 数量的平方增长，而阈值按 `n` 线性增长；窗口太短时
`r/n` 上不去（§1 公式里 `n` 必须大于 `p(1+T/5)`）。窗口收缩机制对极短同聚物有额外帮助，
但下限仍然存在（`A7` 是 7 bp）。

短 + 单个突变更容易漏：`(CA)6`（12 bp，刚好压线）中间替换 1–2 个碱基即变为未检出。

### 3.3 退化重复（分歧率高）

10 组随机替换、统计检出次数（默认参数）：

| 替换率 | `(CA)60` 120 bp | `(CAG)50` 150 bp | `(AACGT)40` 200 bp | `(p12)20` 240 bp |
| --- | --- | --- | --- | --- |
| 0% | 10/10 | 10/10 | 10/10 | 10/10 |
| 5% | 10/10 | 10/10 | 10/10 | 7/10 |
| 10% | 10/10 | 10/10 | 10/10 | 1/10 |
| 15% | 10/10 | 10/10 | 10/10 | 1/10 |
| 20% | 10/10 | 10/10 | 9/10 | 0/10 |
| 25% | 9/10 | 9/10 | 8/10 | 0/10 |
| 30% | 8/10 | 8/10 | 3/10 | 2/10 |
| 35% | 5/10 | 6/10 | 2/10 | 1/10 |
| 40% | 5/10 | 1/10 | 1/10 | 1/10 |

原因：一个替换会破坏最多 3 个相邻 3-mer（产生 3 个“新”3-mer），窗口内相同 3-mer 的对数迅速下降。
**周期越大越敏感**：同样的替换率下，周期 12 的重复几乎没有冗余的 3-mer 可供“稀释”。

判读时注意：高分歧率下的 1–2/10 命中多数只覆盖重复的一小段（局部片段偶然达标），
不应视为整段 STR 被正确标记。

### 3.4 被非 ACGT 字符打断

只有 `A/C/G/T`（大小写均可）参与计算；`N`、IUPAC 模糊碱基（`R/Y/S/W/...`）、
gap（`-`）、`*` 等一律切断片段（映射为 4）。

```
(CA)20 + N + (CA)20   →  100 140 和 141 205（两段分别达标；第二段尾部外扩）
(CA)20 + R + (CA)20   →  与上者完全相同
(CA)6  + N + (CA)6    →  100 112（第一段正常）和 155 177（第二段坐标漂移，实际位于 113–125）
(CA)5  + N + (CA)5    →  两段都短于 12 bp 下限，无有效区间（只剩 N 后方的漂移区间）
```

需要各段**独立**达到 §1 的长度门槛；若 `N` 恰好把一个 STR 切在两个亚阈值片段上，整段就会漏检。

> 注意：滑窗内部计数不会在 `N` 处清零，所以 `N` 之后的片段坐标可能整体平移，
> 且片段越短、平移越明显（详见 §4）。

### 3.5 本来就不是“串联低复杂度”

| 模式 | 例子 | 结果 |
| --- | --- | --- |
| 散在重复（interspersed） | 200 bp 唯一片段相距 500 bp 出现 2 次；相距 300 bp 出现 3 次 | 无输出 |
| 倒位 / 回文重复 | 单元与其反向互补序列相邻 | 每段自身是高复杂度，不产生 3-mer 富集 |

原因：DUST 只统计**同一条链上完全相同的 3-mer**，不做比对、不做重复序列发现。
散在重复与倒位重复的每一段自身是高复杂度序列，掩蔽它们是“正确”的行为，
但这也意味着：**sdust 不能当 repeat finder 用**，检测不到不等于该重复生物学上不存在。

### 3.6 参数导致的漏检

| `-t` | 同聚物下限 | 最短长度公式 | 默认 `-w 64` 下最大周期 |
| --- | --- | --- | --- |
| 5 | 4 bp | `2p+2` | ≈ 31 |
| 10 | 5 bp | `3p+2` | ≈ 21 |
| 20（默认） | 7 bp | `5p+2` | 12 |
| 30 | 9 bp | `7p+2` | 8 |
| 50 | 13 bp | `11p+2` | 5 |

* `-t` 调大：阈值变严，短重复与大周期重复成片漏检。
* `-w` 调小到 `5p+2` 以下：对应周期的重复直接漏检（如 `-w 32` 检不出 p=12 的 72 bp 重复）。
* `-w` 调大不会“稀释”已达标的长重复（`(p12)6` 在 `-w 256` 下仍检出），
  但会让报出的区间向外扩张得更多，见 §4。

## 4. 坐标陷阱：判读输出时要注意

1. 区间是**按窗口整体**报出的，不是精确的重复边界：起点可能早于重复（默认最多约 `W-3` 个碱基），
   终点可能越过重复末尾，甚至越过序列末尾（README 中有同样提示）。
2. `N` 之后的短重复，坐标会整体平移（滑窗记账跨 `N` 延续，片段越短平移越多）：

   ```
   序列：随机40bp + N + A7                长度 48，A7 实际位于 [41,48)
   输出：x  79  86                        ← 起点已超出序列长度

   序列：随机100bp + (CA)6 + N + (CA)6    第二段实际位于 [113,125)
   输出：100 112（第一段）与 155 177      ← 第二段被平移了 +42 bp
   ```

3. 序列 3' 端附近偶尔会出现与低复杂度无关的 ~7 bp 短区间：

   ```
   序列：随机100bp + A20 + 随机100bp   长度 220
   输出：100 123  与  206 213          ← 后者是伪区间
   ```

因此判断“某个 STR 是否被检出”时，应使用**区间集合与重复区是否有重叠**，
并接受“窗口级”的坐标误差，不要用精确起止坐标做断言。

## 5. 实践建议

* 只做掩蔽（masking）、去掉组装中的低复杂度区域：默认参数足够，周期 > 12 的重复本来也不是
  DUST 的设计目标。
* 需要覆盖长周期重复（小卫星、周期 13–40 的串联重复）：把 `-w` 设为 `5p+2` 以上；
  `-w` 越大，高重复输入的时间开销增长越明显。
* 需要更高灵敏度（短 STR 或高分歧 STR）：降低 `-t`，代价是随机序列的假阳性上升。
* 要做 STR **分型**（motif、拷贝数、中断结构）：请勿使用 sdust，改用专门工具
  （Tandem Repeats Finder、HipSTR、ExpansionHunter 等）。

### 把同聚物下限降到 5 bp

```sh
sdust -t 12 in.fa            # -w 保持默认 64 即可
```

* **`-t 12`**：干净 5 bp 同聚物 4/4 检出，且留有余量；`-t 10` 也可以，灵敏度与代价几乎相同。
* **`-t 14` 是硬上限**：5 bp 同聚物只有 3 个 3-mer（`AAA`），窗口收缩后的门限是
  `10 × 3 > 2T`，即 `T < 15`；`-t 15` 及以上一律检不出（实测 0/4），所以不要贴着 14 用。
* **`-w` 不需要改**：同聚物靠“过表达 3-mer 收缩窗口”达标，与窗口长度无关
  （实测 `-w 5 … 1024` 都能检出；`-w 4` 及以下才失效）。

代价（5 kb × 5 条纯随机序列，统计被掩蔽碱基比例）：

| `-t` | 干净 5 bp 同聚物 | 随机序列掩蔽率 |
| --- | --- | --- |
| 20（默认） | 0/4 | 0.09% |
| 15 | 0/4 | 0.40% |
| 14 | 4/4 | 1.30% |
| 12 | 4/4 | 1.52% |
| 10 | 4/4 | 1.62% |

也就是说，代价是随机序列的假阳性从 ~0.1% 升到 ~1.5%，输出里会多出若干 6–7 bp 的短区间：

```sh
python3 -c 'import random; r=random.Random(7); f=lambda n: "".join(r.choice("ACGT") for _ in range(n)); print(">a5"); print(f(100)+"C"+"AAAAA"+"C"+f(100))' > /tmp/a5.fa
./target/release/sdust /tmp/a5.fa            # 无输出（默认 -t 20）
./target/release/sdust -t 12 /tmp/a5.fa
# a5  101  106      ← 目标 5 bp 同聚物
# a5  132  137      ← 随机尾段上的假阳性
```

如果只想对个别位点放宽、其余区域保持默认灵敏度：sdust 没有按 motif 设置阈值的参数，
可以“默认参数跑一遍 + 自己扫描目标区间”两遍处理，或对 `-t 12` 的输出按长度/位置过滤。

## 6. 复现

```sh
cargo build --release

# 周期 13 的 2000 bp 重复：默认参数无输出，-w 67 起可检出
python3 -c 'print(">p13"); print("ACGGGATGTTTAG"*153)' > /tmp/p13.fa
./target/release/sdust /tmp/p13.fa            # 无输出
./target/release/sdust -w 67 /tmp/p13.fa      # p13  0  1989（窗口级区间）

# 同聚物下限：6 bp 无输出，7 bp 检出
python3 -c 'print(">a6"); print("A"*6)' > /tmp/a6.fa
python3 -c 'print(">a7"); print("A"*7)' > /tmp/a7.fa
./target/release/sdust /tmp/a6.fa             # 无输出
./target/release/sdust /tmp/a7.fa             # 0  7

# 用“首次检出的 -w”验证 5p+2
python3 - <<'PY'
import subprocess
seq = "CTGAATGCCTAGGTACCGATTGCAAGTCGATCGGATCTAA" + "CTCCCGCATTTA"*100
open("/tmp/p12.fa", "w").write(">x\n" + seq + "\n")
for w in range(3, 90):
    out = subprocess.run(["./target/release/sdust", "-w", str(w), "/tmp/p12.fa"],
                         capture_output=True, text=True).stdout
    if out.strip():
        print("p=12 首次检出 -w =", w); break
PY
```
