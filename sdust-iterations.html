一个问题，六版策略：
低复杂度检测是这样一步步演化出来的

业务问题只有一个：基因组里的低复杂度区域（poly-A、AT 重复、微卫星）会污染比对和搜索， 需要一个工具给出它们的精确坐标。但"什么叫重复"这件事，先后有过六版完全不同的回答—— 每一版都是被上一版的失效方式逼出来的。这条路线的终点，就是本项目实现的 symmetric DUST 策略。

v1 的死因

组成频率对周期性重复天然钝化：AT 重复里 A、T 各 50%，ACGT 串联里四种碱基各 25%—— 组成"完全正常"，但序列毫无信息量。给每个碱基单独设阈值，阈值表越写越长，还是漏。

v2 为什么是「配对」而不是「最高频次」

最高频次只看一条路，多路同时重复时信号被摊薄（六路重复里最高频词只占 17%）。 配对计数 ΣC(c,2) 把所有重复子串的重复度加起来， 并且二次放大：出现 8 次 = 28 对，16 次 = 120 对。

最终策略：perfect 区间提取 + 合并（青）——只掩真正重复的部分
—整窗报告掩掉的碱基
—完美提取掩掉的碱基
—v2 多掩的干净碱基

v2 的另一个失效方式是方向依赖：它在窗口内只提取一个"最优子区间"，而提取从哪一端开始是任意的—— 同一个窗口在反链上会提取出不同的区间。symmetric DUST 的回答：枚举窗口内所有起点的候选子区间， 只保留"密度不被右侧任何已保留区间支配"的（Pareto 前沿），输出由整条流决定而非单个窗口——正反链因此镜像一致， 可以在④的实验室里用反向互补亲自验证。

06
the strategy, stated

最终形态的策略，一句话与五条原则

一句话：低复杂度 = 子串重复异常。用可增量维护、且对链方向不变的量（3-mer 配对数）度量它， 用与长度无关的比值（10r > T·n）判定它，只在窗口可疑时回溯提取 Pareto 最优子区间， 等窗口左界越过区间起点后才确定输出。

01 / MEASURE

度量对象：子串重复，不是碱基组成

组成频率对周期重复钝化；3-mer 配对计数把"所有重复子串的重复度"加总，且 64 个桶整个放进 L1。

win_count / ring_count [64]
02 / NORMALIZE

阈值必须是比值，不是分数

10r > T·n 让左右同阶增长——窗口从满长收缩到更短时判定仍然可比。这是后续一切收缩策略的前提。

mask() 里的唯一判定式
03 / GRANULARITY

判定下沉到子区间层面

窗口只是"探测器"，输出由 perfect 区间（Pareto 前沿）决定。区间因此不依赖窗口划分，正反链镜像一致。

find_perfect 的 r·maxL ≥ maxR·l
04 / LAZINESS

计算是懒的：先门控，后回溯

分数 O(1) 增量维护；只有 10·ring_pairs > T·ring_len 时才向左枚举。随机区几乎零成本，成本集中在重复区。

mask() 里的 if 门控
05 / STREAMING

输出流式确定化

窗口左界越过区间起点，它就不可能再变长——此刻才输出并合并。内存 O(W)，与序列长度无关。

save_masked_regions
06 / CONTRACT

边界交给契约，不交给聪明

N 切断片段；区间可以略超出重复片段（窗口级报告）；尾部用哨兵刷新。"看起来不对"的地方先问是不是契约。

07
rejected alternatives

被淘汰的路线，和被淘汰的原因

碱基组成频率

v1。对 AT / ACGT 周期重复钝化（组成完全正常），阈值表越写越长。见上方①的对比表。

最高词频 > 固定占比

多路同时重复时信号被摊薄（六路重复最高频只占 17%），且"占比阈值"没有自然定义、随重复路数漂移。

k = 2 或 k ≥ 4

k=2 在随机序列里误报多（二核苷酸撞车太常见）；k≥4 漏掉 AT、AAG 这类短周期，且桶数暴涨。k=3 是灵敏度与成本的交点。

窗口硬切分报告

同一个重复在不同窗口划分下得分不同、报告不同。完美提取 + 延迟确定化让输出由整条流决定。
